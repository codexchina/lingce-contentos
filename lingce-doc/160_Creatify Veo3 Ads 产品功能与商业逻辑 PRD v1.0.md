# 1. 产品概述

Creatify 是面向广告主和增长团队的 AI 广告生成平台。

当前页面重点是：

```text
Veo3 Ads
```

一句话定位：

> Creatify Veo3 Ads 是将产品图片、链接或描述快速转成高真实感视频广告的 AI 广告制作器。

页面主张：

* 几秒钟内将产品转化为视频广告。
* 由 Veo 3 提供支持。
* 无需编辑。
* 支持从产品 URL 生成视频广告。
* 可快速生成多种广告变体。

# 5. 商业逻辑

## 5.1 收入模型

Creatify 主要采用：

```text
免费额度

+

订阅套餐

+

credits 计费

+

API 方案

+

企业 / 代理商方案
```

公开信息显示，免费方案包含月度 credits，可创建少量视频广告或更多图片广告；API 方案存在 Starter、Pro 等更高价位套餐。

---

## 5.2 价值证明

Creatify 页面强调效果数据：

* 支持 18,000+ 品牌和代理商。
* 分析 30M+ 广告。
* 创建 15M+ 广告。
* 覆盖 $1B+ 广告花费。
* 页面声称相对静态广告带来更高 leads、ROI 和更低制作成本。
* Veo3 Ads 页面声称可带来更高 ROAS、更低 CPA。

产品判断：

Creatify 的销售逻辑不是“AI 视频很好玩”，而是“广告创意产能和投放效果提升”。

# 8. 风险

* Veo3 成本较高，credits 定价需要覆盖模型成本。
* 高真实感广告可能带来合规和虚假宣传风险。
* 使用竞品广告克隆时需处理版权和平台政策。
* 效果数据容易被用户理解为承诺，需要明确来源和适用条件。
* 多平台发布涉及广告审核规范差异。

---

# 10. 结论

Creatify Veo3 Ads 的本质不是视频生成器，而是广告创意生产和测试平台。

最值得学习的是：

* 用产品 URL 降低输入成本。
* 用广告风格 / recipe 降低 Prompt 成本。
* 用多变体服务投放测试。
* 用效果数据和 API 拉高商业价值。
