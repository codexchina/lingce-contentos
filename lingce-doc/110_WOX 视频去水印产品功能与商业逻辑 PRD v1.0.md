# 1. 产品概述

## 1.1 产品名称

```text
WOX 电商设计平台
```

重点分析工具：

```text
视频去水印
```

英文名称：

```text
VIDEO WATERMARK REMOVAL
```

---

## 1.2 产品定位

WOX 是面向电商商家的 AI 视觉设计与内容创作平台。

它不是单点 AI 工具，而是一个围绕电商内容生产的工作台：

```text
商品素材

↓

AI 创作工具

↓

生成任务

↓

结果资产

↓

下载 / 发布 / 复用 / 再创作
```

平台通过图片创作、视频创作、小工具、无限画布和灵感社区，把电商视觉生产中的多个高频场景组织在一起。

---

## 1.3 当前工具定位

`视频去水印` 是 WOX 小工具 / 视频处理能力中的一个轻量工具。

核心目标：

> 用户上传原视频后，系统自动移除画面水印，输出更干净、可继续使用的视频素材。

核心价值：

* 降低素材清洗成本。
* 提升电商运营素材复用效率。
* 把复杂视频修复能力包装成低门槛上传式工具。
* 为后续高清修复、视频编辑、广告片生成等能力导流。

# 2. 用户与场景

## 2.1 目标用户

WOX 的核心用户包括：

* 淘宝、抖音、快手、小红书、亚马逊等平台的电商卖家。
* 服装、鞋包、配饰等类目的品牌方。
* 电商设计师。
* 摄影修图团队。
* 短视频运营团队。
* 内容搬运、素材整理、投放测试人员。

---

## 2.2 用户痛点

典型痛点：

* 原始素材带有平台、拍摄工具、样片或历史版本水印。
* 人工去水印需要剪辑软件和修复经验，时间成本高。
* 电商运营需要快速清洗大量素材。
* 素材处理后还需要继续做高清修复、剪辑、口播、广告片生成。
* 用户不关心模型参数，只关心结果是否干净、能不能下载使用。

---

## 2.3 使用场景

| 场景 | 用户目标 |
|---|---|
| 电商素材清洗 | 去掉样片、工具、平台水印，得到可继续编辑的视频素材 |
| 旧素材复用 | 把历史视频处理干净后用于新活动、新渠道 |
| 投放素材准备 | 在广告剪辑前先统一清理画面 |
| 短视频二创前处理 | 对已有授权素材进行去水印、高清修复和再编辑 |
| 批量运营处理 | 大量素材快速处理，减少人工剪辑时间 |

## 4.4 功能需求

### 4.4.1 视频上传

用户可以上传原始视频文件。

基础要求：

* 支持常见视频格式。
* 上传前校验文件类型。
* 上传前校验文件大小。
* 上传后显示文件名、大小和上传状态。
* 上传失败时展示可理解错误原因。

建议支持格式：

```text
mp4
mov
webm
```

---

### 4.4.2 任务创建

用户点击生成后，系统创建去水印任务。

任务创建需要完成：

* 校验用户登录状态。
* 校验账户余额或积分是否足够。
* 校验视频素材是否已上传。
* 生成任务记录。
* 调用上游 RunningHub 工作流。
* 返回任务 ID。

---

### 4.4.3 任务进度

任务运行中需要展示：

* 当前状态。
* 进度百分比。
* 预计等待提示。
* 失败原因。
* 可取消操作。

任务状态建议：

| 状态 | 说明 |
|---|---|
| pending | 等待创建 |
| queued | 排队中 |
| running | 处理中 |
| succeeded | 已完成 |
| failed | 失败 |
| cancelled | 已取消 |

---

### 4.4.4 结果展示

任务成功后展示处理后视频。

结果区需要支持：

* 视频预览。
* 下载单个结果。
* 多结果时打包下载。
* 移动端打开原视频后长按保存。
* 可继续发布到创作社区。
* 可加入画布进行后续创作。

---

### 4.4.5 历史任务

系统应保存用户历史任务。

历史任务字段建议：

| 字段 | 说明 |
|---|---|
| taskId | 平台任务 ID |
| feature | 功能 slug |
| kind | 输出类型 |
| status | 任务状态 |
| sourceAsset | 原始视频素材 |

| estimatedCost | 预估消耗 |

# 6. 计费与账户逻辑

## 6.1 账户结构

WOX 账户中至少存在两类余额：

```text
积分

账户现金
```

页面顶部会展示：

```text
0 积分｜¥0.00
```

---

## 6.2 积分用途

积分是平台统一的创作权益单位。

可用于：

* 免费模型能力结算。
* 平台权益消耗。
* 社区激励发放。
* 用户任务消耗记录。

---

## 6.3 账户现金用途

账户现金用于需要按上游 API 成本结算的付费模型。

适合承接：

* 高成本视频生成。
* 第三方模型 API。
* RunningHub 等上游服务。
* 需要真实成本核算的任务。

---

## 6.4 计费流程

建议计费流程：

```text
用户提交任务

↓

系统预估消耗

↓

余额校验

↓

预授权 / 冻结额度

↓

调用上游服务

↓

任务成功后正式扣费

↓

任务失败后退回额度
```

---

## 6.5 错误提示逻辑

可识别错误类型：

| 错误 | 用户提示 |
|---|---|
| 账户余额不足 | 账号余额不足，请充值即可 |
| 上游额度不足 | 模型服务额度暂时不可用，请联系平台处理；无需重复充值 WOX 账户 |
| 上游鉴权失败 | 模型服务连接验证失败，请联系平台管理员 |
| 上游限流 | 模型服务繁忙，请稍后重试 |
| 模型渠道不可用 | 当前模型渠道不可用，请切换模型或联系平台管理员 |
| 参数不支持 | 当前模型不支持本次参数组合，请检查时长、画幅与参考素材 |

产品判断：

WOX 已经有意识地区分了“用户余额不足”和“上游服务问题”，这对降低客服压力很重要。

# 8. 产品护城河

## 8.1 弱护城河能力

以下单点功能容易被替代：

* 视频去水印。
* 图片去水印。
* 高清修复。
* 文生视频。
* 图生视频。
* 简单海报生成。

原因：

* 上游模型和工作流可替换。
* 用户迁移成本低。
* 单点工具难形成长期留存。

---

## 8.2 强护城河能力

WOX 更有价值的护城河在于：

* 电商行业场景理解。
* 服装视觉模板。
* 数字模特和服装素材资产沉淀。
* 任务历史和结果资产。
* 一键同款社区。
* 从图片到视频的连续生产链路。
* 积分、现金、会员组合的商业体系。

一句话判断：

> 单个工具不是护城河，围绕电商视觉生产形成的持续工作流才是护城河。

# 9. 合规与风险

## 9.1 内容版权风险

去水印和一键提取类工具存在版权风险。

产品必须明确：

* 仅支持用户处理自有版权素材。
* 仅支持处理已获得授权的素材。
* 禁止绕过平台版权保护。
* 禁止盗用他人作品。
* 生成结果由用户承担使用责任。

---

## 9.2 上游依赖风险

大量能力依赖 RunningHub 工作流，会带来：

* 上游服务不可用风险。
* 上游成本变化风险。
* 上游接口变更风险。
* 上游结果质量波动风险。
* 上游额度不足风险。

建议：

* 对同类能力维护多个 Provider。
* 记录每次任务的 Provider、版本和参数。
* 对高频能力逐步建立自有工作流。
* 对用户隐藏上游错误细节，但内部保留完整日志。

---

## 9.3 计费透明风险

积分、账户现金、会员套餐同时存在，容易造成用户困惑。

需要明确：

* 每次任务预计消耗。
* 实际扣费。
* 失败退款。
* 积分和现金的区别。
* 哪些功能使用积分，哪些功能使用现金。

# 12. 结论

WOX 视频去水印工具本身是一个轻量、高频、明确结果导向的素材处理工具。

但它真正的产品价值不在单点去水印，而在它被放进了 WOX 的完整电商视觉生产系统中：

```text
素材处理

↓

图片生成

↓

视频生成

↓

高清修复

↓

广告成片

↓

社区复用
```

因此，复刻此类产品不能只做一个上传按钮和模型调用接口，而应同时设计：

* 任务系统。
* 资产系统。
* 结算系统。
* Provider 接入层。
* 结果下载与复用。
* 社区或模板增长机制。
* 合规边界。

一句话总结：

> AI 工具的商业价值，不来自单个模型按钮，而来自对高频生产流程的包装、结算、资产沉淀和复用网络。
